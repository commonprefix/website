## Axelar Amplifier integration with XRPL

Common Prefix has partnered with Axelar to integrate Ripple's XRP Ledger (XRPL) with Axelar's Amplifier interoperability infrastructure. This integration enables bridging assets between XRPL and all Axelar-supported chains. It also allows smart contracts on other chains to be called directly from XRPL.

- [XRPL smart contracts GitHub repo](https://github.com/axelarnetwork/axelar-amplifier-xrpl) (2023-11-20 – present)
- [XRPL verifier node](https://github.com/axelarnetwork/axelar-amplifier/tree/main/ampd/src/xrpl) (2023-11-20 – present)
- [XRPL relayer GitHub repo](https://github.com/axelarnetwork/axelar-relayer-xrpl) (2024-02-20 – present)

## Ethereum Light Client on Axelar implementation

Common Prefix collaborated with Axelar to develop a light client that employs Ethereum's Sync Committee protocol to bridge events from Ethereum to Axelar.
